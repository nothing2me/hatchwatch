# NestTrace Dashboard — Plan 1: Foundation and Map — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Vite demo in `dashboard/` with a Dockerised Next.js + Postgres app that has login with roles, seeded zones/cameras in real coordinates, and the read-only Night Watch satellite map (zoom, fit, layer toggles, collapsible legend, camera panel, alerts feed).

**Architecture:** `dashboard/docker-compose.yml` runs `db` (Postgres 16) and `web` (Next.js 16 App Router). `web` owns the full Prisma schema from the spec (later plans add the worker and write paths), a small cookie-session auth (argon2 + signed JWT via `jose`), and server-rendered pages that pass a typed `MapSnapshot` to client map components built on MapLibre GL through `react-map-gl/maplibre`.

**Tech Stack:** Next.js 16.4.0, React 19.3.0, TypeScript 5.9.3, Tailwind CSS 4.3.3, Radix Collapsible 1.1.21, lucide-react 1.54.0, motion 14.1.0, Prisma 7.10.0 with `@prisma/adapter-pg` 7.10.0, Postgres 16, jose 6.2.12, @node-rs/argon2 2.2.2, zod 4.6.5, maplibre-gl 6.13.0, react-map-gl 8.1.3, Vitest 5.0.3, Testing Library 16.3.3, jsdom 30.1.2.

**Spec:** `docs/superpowers/specs/2026-10-09-nesttrace-dashboard-design.md`

**Plan series:** Plan 1 (this) — foundation and map. Plan 2 — upload, job queue, Python worker (tracker + detector adapter), SSE progress, playback bar. Plan 3 — alerts workflow, setup (zones, cameras, calibration), Playwright end-to-end. Plans 2 and 3 are written after Plan 1 lands so they can reference real code.

## Global Constraints

- Everything lives under `dashboard/`. Never import from repo-root `web/`, call `scripts/server.mjs` / port 5174, or read any `private/` path (spec §1, `agent.md`).
- Detector alert message is exactly `Digging activity detected; nesting unresolved.`; track-only message `Crawl tracked; digging not observed.`; no-turtle message `No turtle tracked.` No UI text says a nest is confirmed except "Field-confirmed by <name>" (spec §3).
- Ports: web 3000; Postgres exposed to host on 5433 (container 5432). Research app keeps 5173/5174.
- Env vars: `DATABASE_URL`, `AUTH_SECRET`, `MEDIA_ROOT=/media`, `SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD`, `MAX_UPLOAD_MB=500`.
- Roles: `ADMIN`, `VIEWER`. Every mutation checks role on the server.
- Night Watch tokens: background `#070D13`/`#0A1118`, panel `rgba(8,14,20,0.82)` + 8px blur + `1px rgba(255,255,255,0.08)` border, text `#D7E3EA`, single accent amber `#FFB547` (attention only), danger `#E2581F`, ok `#4ADE80`. Fonts Inter (UI) and JetBrains Mono (numbers/timecodes).
- Satellite tiles: Esri World Imagery `https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}` plus labels `https://server.arcgisonline.com/ArcGIS/rest/services/Reference/World_Boundaries_and_Places/MapServer/tile/{z}/{y}/{x}`; attribution `Esri, Maxar, Earthstar Geographics`.
- Node ≥ 24 in containers (`node:24-bookworm-slim`).

**Deviations from the spec, decided while planning (call out in review):**
- Auth uses a ~60-line cookie session (argon2 + `jose` JWT) instead of Auth.js: the stable `next-auth` is v4 and v5 is still beta (`5.0.0-beta.32`), and neither documents Next 16 support. Same behavior as spec §4 (`/login`, email + password, JWT session, roles).
- shadcn/ui components are written by hand in shadcn style (Radix primitive + `cn()` + Tailwind) rather than generated by the interactive CLI. Only the few needed components are added.
- `Camera` gains `rangeM` (view-cone length in metres) for drawing cones; the spec's `Camera` lacked a length.
- Route protection is done in the `(app)` server layout and in each handler, not in Next middleware/proxy.

## Review Focus

1. **Expired or tampered session cookie** → user is sent to `/login`, never a 500. Pinned in Task 3 (`readSessionToken` returns `null` for bad signature and for expired tokens).
2. **Re-running the seed on an existing database** (every `docker compose up`) → no duplicates, no overwritten admin password. Pinned in Task 2 (seed idempotence test).
3. **Map tiles unreachable (offline demo)** → zones, cameras and panels still render over a dark background, with an "Imagery offline" notice. Pinned in Task 5 (`buildMapStyle` keeps a background layer under rasters; `MapView` shows notice on tile `error`).
4. **Viewer hitting an admin-only URL directly** → 403 page, not a crash or a silent render. Pinned in Task 3 (`requireRole` test) and Task 4 (`/setup` placeholder gate).
5. **Narrow phone width** → panels collapse to bottom sheet / hidden list, no horizontal scroll. Pinned in Task 6 (layout test asserts panels use `md:` classes and the feed toggle exists).

`dashboard/web/prisma/schema.prisma`:
```prisma
generator client {
  provider = "prisma-client"
  output   = "../src/generated/prisma"
}

datasource db {
  provider = "postgresql"
}

enum Role {
  ADMIN
  VIEWER
}

enum ActivityLevel {
  LOW
  MEDIUM
  HIGH
}

enum CameraStatus {
  ONLINE
  OFFLINE
}

enum JobStatus {
  QUEUED
  RUNNING
  DONE
  FAILED
}

enum JobStage {
  probe
  calibrate
  extract
  detect
  track
  render
  persist
}

enum AlertKind {
  DIGGING
  TRACK_ONLY
  NO_TURTLE
}

enum AlertStatus {
  NEW
  REVIEWED
  DISMISSED
  FIELD_CONFIRMED
}

model User {
  id            String              @id @default(cuid())
  email         String              @unique
  passwordHash  String
  name          String
  role          Role                @default(VIEWER)
  createdAt     DateTime            @default(now())
  videos        Video[]
  notes         AlertNote[]
  statusChanges AlertStatusChange[]
  auditLogs     AuditLog[]
}

model Zone {
  id            String        @id @default(cuid())
  code          String        @unique
  name          String
  /// GeoJSON Polygon: { type: "Polygon", coordinates: [[[lng, lat], ...]] }
  outline       Json
  activityLevel ActivityLevel @default(LOW)
  cameras       Camera[]
  alerts        Alert[]
}

model Camera {
  id          String       @id @default(cuid())
  code        String       @unique
  zoneId      String
  zone        Zone         @relation(fields: [zoneId], references: [id])
  lng         Float
  lat         Float
  /// Compass bearing in degrees, 0 = north, clockwise.
  headingDeg  Float
  fovDeg      Float        @default(44)
  /// Length of the drawn view cone in metres.
  rangeM      Float        @default(250)
  status      CameraStatus @default(ONLINE)
  /// { pairs: [{ px: [x, y], lngLat: [lng, lat] }] (4), frameWidth, frameHeight, rmseM }
  calibration Json?
  videos      Video[]
  alerts      Alert[]
}

model Video {
  id           String   @id @default(cuid())
  cameraId     String
  camera       Camera   @relation(fields: [cameraId], references: [id])
  path         String
  originalName String
  durationS    Float?
  fps          Float?
  width        Int?
  height       Int?
  uploadedById String
  uploadedBy   User     @relation(fields: [uploadedById], references: [id])
  createdAt    DateTime @default(now())
  jobs         Job[]
  tracks       Track[]
  alerts       Alert[]
}

model Job {
  id          String    @id @default(cuid())
  videoId     String
  video       Video     @relation(fields: [videoId], references: [id])
  status      JobStatus @default(QUEUED)
  stage       JobStage?
  progress    Float     @default(0)
  attempts    Int       @default(0)
  error       String?
  heartbeatAt DateTime?
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt

  @@index([status, createdAt])
}

model Track {
  id            String  @id @default(cuid())
  videoId       String
  video         Video   @relation(fields: [videoId], references: [id])
  /// [{ t, px, py, lng?, lat? }]
  points        Json
  startT        Float
  endT          Float
  geoReferenced Boolean @default(false)
  label         String
}

model Alert {
  id                    String              @id @default(cuid())
  videoId               String
  video                 Video               @relation(fields: [videoId], references: [id])
  cameraId              String
  camera                Camera              @relation(fields: [cameraId], references: [id])
  zoneId                String
  zone                  Zone                @relation(fields: [zoneId], references: [id])
  kind                  AlertKind
  message               String
  score                 Float?
  lng                   Float?
  lat                   Float?
  radiusM               Float               @default(0.9)
  startT                Float
  endT                  Float
  status                AlertStatus         @default(NEW)
  outsideCalibratedArea Boolean             @default(false)
  createdAt             DateTime            @default(now())
  notes                 AlertNote[]
  statusChanges         AlertStatusChange[]

  @@index([status, createdAt])
}

model AlertNote {
  id        String   @id @default(cuid())
  alertId   String
  alert     Alert    @relation(fields: [alertId], references: [id])
  userId    String
  user      User     @relation(fields: [userId], references: [id])
  body      String
```

```ts
import 'dotenv/config';
import { randomBytes } from 'node:crypto';
import { hash } from '@node-rs/argon2';
import type { PrismaClient } from '../src/generated/prisma/client';
import { DEMO_VIEWER, SEED_CAMERAS, SEED_ZONES } from './seed-data';

export interface SeedOptions
{
    adminEmail: string;
    adminPassword: string;
}

// Safe to run on every container start: creates what is missing and leaves
// existing rows (including edited zones and changed passwords) untouched.
export async function seedDatabase(prisma: PrismaClient, options: SeedOptions): Promise<void>
{
    for (const zone of SEED_ZONES)
    {
        await prisma.zone.upsert({
            where: { code: zone.code },
            update: {},
            create: { code: zone.code, name: zone.name, activityLevel: zone.activityLevel, outline: zone.outline },
        });
    }

    for (const camera of SEED_CAMERAS)
    {
        const zone = await prisma.zone.findUniqueOrThrow({ where: { code: camera.zoneCode } });
        await prisma.camera.upsert({
            where: { code: camera.code },
            update: {},
            create: {
                code: camera.code,
                zoneId: zone.id,
                lng: camera.lng,
                lat: camera.lat,
                headingDeg: camera.headingDeg,
                fovDeg: camera.fovDeg,
                rangeM: camera.rangeM,
                status: camera.status,
            },
        });
    }

    await prisma.user.upsert({
        where: { email: options.adminEmail },
        update: {},
        create: { email: options.adminEmail, name: 'Admin', role: 'ADMIN', passwordHash: await hash(options.adminPassword) },
    });

    const viewerExists = await prisma.user.findUnique({ where: { email: DEMO_VIEWER.email } });
    if (!viewerExists)
    {
        const viewerPassword = randomBytes(9).toString('base64url');
        await prisma.user.create({
            data: { email: DEMO_VIEWER.email, name: DEMO_VIEWER.name, role: 'VIEWER', passwordHash: await hash(viewerPassword) },
        });
        if (process.env.NODE_ENV !== 'test')
        {
            console.log(`Seeded viewer ${DEMO_VIEWER.email} with password: ${viewerPassword}`);
        }
    }
}

// CLI entry: `tsx prisma/seed.ts`
if (import.meta.url === `file://${process.argv[1]}`)
{
    const { createPrismaClient } = await import('../src/lib/db');
    const adminEmail = process.env.SEED_ADMIN_EMAIL;
    const adminPassword = process.env.SEED_ADMIN_PASSWORD;
    if (!adminEmail || !adminPassword)
    {
        throw new Error('SEED_ADMIN_EMAIL and SEED_ADMIN_PASSWORD must be set');
    }
    const prisma = createPrismaClient();
    await seedDatabase(prisma, { adminEmail, adminPassword });
    await prisma.$disconnect();
    console.log('Seed complete');
}
```

```ts
import { jwtVerify, SignJWT } from 'jose';
import { z } from 'zod';
import type { Role } from '@/lib/types';

export interface SessionUser
{
    id: string;
    email: string;
    name: string;
    role: Role;
}

export const SESSION_COOKIE = 'nt_session';
export const SESSION_TTL_SECONDS = 7 * 24 * 3600;

const payloadSchema = z.object({
    sub: z.string().min(1),
    email: z.string().email(),
    name: z.string(),
    role: z.enum(['ADMIN', 'VIEWER']),
});

function key(secret: string): Uint8Array
{
    return new TextEncoder().encode(secret);
}

export async function createSessionToken(user: SessionUser, secret: string, now: Date = new Date()): Promise<string>
{
    const issuedAt = Math.floor(now.getTime() / 1000);
    return new SignJWT({ email: user.email, name: user.name, role: user.role })
        .setProtectedHeader({ alg: 'HS256' })
        .setSubject(user.id)
        .setIssuedAt(issuedAt)
        .setExpirationTime(issuedAt + SESSION_TTL_SECONDS)
        .sign(key(secret));
}

// Any failure (bad signature, expired, malformed, unknown role) means "no session".
export async function readSessionToken(token: string | undefined, secret: string): Promise<SessionUser | null>
{
    if (!token)
    {
        return null;
    }

    try
    {
        const { payload } = await jwtVerify(token, key(secret), { algorithms: ['HS256'] });
        const parsed = payloadSchema.safeParse(payload);
        if (!parsed.success)
        {
            return null;
        }
        return { id: parsed.data.sub, email: parsed.data.email, name: parsed.data.name, role: parsed.data.role };
    }
    catch
    {
        return null;
    }
}

export function sessionCookieOptions()
{
    return {
        httpOnly: true as const,
        sameSite: 'lax' as const,
        secure: process.env.NODE_ENV === 'production' && process.env.INSECURE_COOKIES !== '1',
        path: '/' as const,
        maxAge: SESSION_TTL_SECONDS,
    };
}
```

```ts
import 'server-only';
import { cookies } from 'next/headers';
import { forbidden, redirect } from 'next/navigation';
import type { Role } from '@/lib/types';
import { readSessionToken, SESSION_COOKIE, type SessionUser } from './session';

const rank: Record<Role, number> = { VIEWER: 1, ADMIN: 2 };

export function hasRole(user: SessionUser | null, role: Role): boolean
{
    return user !== null && rank[user.role] >= rank[role];
}

function authSecret(): string
{
    const secret = process.env.AUTH_SECRET;
    if (!secret || secret.length < 32)
    {
        throw new Error('AUTH_SECRET must be set to at least 32 characters');
    }
    return secret;
}

export async function getSession(): Promise<SessionUser | null>
{
    const store = await cookies();
    return readSessionToken(store.get(SESSION_COOKIE)?.value, authSecret());
}

export async function requireUser(): Promise<SessionUser>
{
    const user = await getSession();
    if (!user)
    {
        redirect('/login');
    }
    return user;
}

export async function requireRole(role: Role): Promise<SessionUser>
{
    const user = await requireUser();
    if (!hasRole(user, role))
    {
        forbidden();
    }
    return user;
}
```

```ts
'use server';

import { cookies } from 'next/headers';
import { redirect } from 'next/navigation';
import { z } from 'zod';
import { prisma } from '@/lib/db';
import { verifyPassword } from '@/lib/auth/password';
import { createSessionToken, SESSION_COOKIE, sessionCookieOptions, type SessionUser } from '@/lib/auth/session';
import { authSecret } from '@/lib/auth/guard';

export type LoginState = { error: string | null };

interface AuthDeps
{
    findUser: (email: string) => Promise<(SessionUser & { passwordHash: string }) | null>;
    verify: (passwordHash: string, plain: string) => Promise<boolean>;
}

const defaultDeps: AuthDeps = {
    findUser: email => prisma.user.findUnique({
        where: { email },
        select: { id: true, email: true, name: true, role: true, passwordHash: true },
    }),
    verify: verifyPassword,
};

export async function authenticate(email: string, password: string, deps: AuthDeps = defaultDeps): Promise<SessionUser | null>
{
    const row = await deps.findUser(email.trim().toLowerCase());
    if (!row || !(await deps.verify(row.passwordHash, password)))
    {
        return null;
    }
    return { id: row.id, email: row.email, name: row.name, role: row.role };
}

const formSchema = z.object({
    email: z.string().email(),
    password: z.string().min(1).max(200),
});

export async function loginAction(_prev: LoginState, form: FormData): Promise<LoginState>
{
    const parsed = formSchema.safeParse({ email: form.get('email'), password: form.get('password') });
    if (!parsed.success)
    {
        return { error: 'Enter your email and password.' };
    }

    const user = await authenticate(parsed.data.email, parsed.data.password);
    if (!user)
    {
        return { error: 'Email or password is incorrect.' };
    }

    const store = await cookies();
    store.set(SESSION_COOKIE, await createSessionToken(user, authSecret()), sessionCookieOptions());
    redirect('/');
}
```

```ts
import type { LngLat } from './types';

const EARTH_RADIUS_M = 6371008.8;
const toRad = (degrees: number) => (degrees * Math.PI) / 180;
const toDeg = (radians: number) => (radians * 180) / Math.PI;

// Great-circle destination from origin along a compass bearing.
export function destinationPoint([lng, lat]: LngLat, bearingDeg: number, distanceM: number): LngLat
{
    const angular = distanceM / EARTH_RADIUS_M;
    const bearing = toRad(bearingDeg);
    const lat1 = toRad(lat);
    const lng1 = toRad(lng);
    const lat2 = Math.asin(Math.sin(lat1) * Math.cos(angular) + Math.cos(lat1) * Math.sin(angular) * Math.cos(bearing));
    const lng2 = lng1 + Math.atan2(Math.sin(bearing) * Math.sin(angular) * Math.cos(lat1), Math.cos(angular) - Math.sin(lat1) * Math.sin(lat2));
    return [toDeg(lng2), toDeg(lat2)];
}

// Pie-slice polygon for a camera's field of view, as a closed ring.
export function viewCone(origin: LngLat, bearingDeg: number, fovDeg: number, rangeM: number, steps = 16): LngLat[]
{
    const start = bearingDeg - fovDeg / 2;
    const arc: LngLat[] = [];
    for (let i = 0; i <= steps; i++)
    {
        arc.push(destinationPoint(origin, start + (fovDeg * i) / steps, rangeM));
    }
    return [origin, ...arc, origin];
}

export function boundsOf(points: LngLat[]): [LngLat, LngLat]
{
    const lngs = points.map(point => point[0]);
    const lats = points.map(point => point[1]);
    return [[Math.min(...lngs), Math.min(...lats)], [Math.max(...lngs), Math.max(...lats)]];
}
```

```ts
import 'server-only';
import { prisma } from '@/lib/db';
import type { ActivityLevel, AlertKind, AlertStatus, CameraStatus, LngLat, MapSnapshot } from '@/lib/types';

export interface ZoneRow
{
    id: string; code: string; name: string; activityLevel: ActivityLevel;
    outline: unknown;
}

export interface CameraRow
{
    id: string; code: string; zone: { code: string };
    lng: number; lat: number; headingDeg: number; fovDeg: number; rangeM: number;
    status: CameraStatus; calibration: unknown; videos: { id: string }[];
}

export interface AlertRow
{
    id: string; kind: AlertKind; message: string; status: AlertStatus;
    zone: { code: string }; camera: { code: string };
    lng: number | null; lat: number | null; radiusM: number; score: number | null; createdAt: Date;
}

export interface SnapshotRows
{
    zones: ZoneRow[];
    cameras: CameraRow[];
    alerts: AlertRow[];
}

function ringOf(outline: unknown): LngLat[]
{
    const coordinates = (outline as { coordinates?: LngLat[][] })?.coordinates;
    return Array.isArray(coordinates?.[0]) ? coordinates[0] : [];
}

export function toMapSnapshot(rows: SnapshotRows): MapSnapshot
{
    const cameras = rows.cameras.map(camera => ({
        id: camera.id,
        code: camera.code,
        zoneCode: camera.zone.code,
        position: [camera.lng, camera.lat] as LngLat,
        headingDeg: camera.headingDeg,
        fovDeg: camera.fovDeg,
        rangeM: camera.rangeM,
        status: camera.status,
        calibrated: camera.calibration !== null,
        latestVideoId: camera.videos[0]?.id ?? null,
    }));

    const alerts = rows.alerts.map(alert => ({
        id: alert.id,
        kind: alert.kind,
        message: alert.message,
        status: alert.status,
        zoneCode: alert.zone.code,
        cameraCode: alert.camera.code,
        position: alert.lng !== null && alert.lat !== null ? [alert.lng, alert.lat] as LngLat : null,
        radiusM: alert.radiusM,
        score: alert.score,
        createdAt: alert.createdAt.toISOString(),
    }));

    return {
        zones: rows.zones.map(zone => ({ id: zone.id, code: zone.code, name: zone.name, activityLevel: zone.activityLevel, ring: ringOf(zone.outline) })),
        cameras,
        alerts,
        camerasOnline: cameras.filter(camera => camera.status === 'ONLINE').length,
        camerasTotal: cameras.length,
        activeAlertCount: alerts.filter(alert => alert.status === 'NEW').length,
    };
}

export async function getMapSnapshot(): Promise<MapSnapshot>
{
    const [zones, cameras, alerts] = await Promise.all([
        prisma.zone.findMany({ orderBy: { code: 'asc' } }),
        prisma.camera.findMany({
            orderBy: { code: 'asc' },
            include: {
                zone: { select: { code: true } },
                videos: { select: { id: true }, orderBy: { createdAt: 'desc' }, take: 1 },
            },
        }),
        prisma.alert.findMany({
            orderBy: { createdAt: 'desc' },
            take: 100,
            include: { zone: { select: { code: true } }, camera: { select: { code: true } } },
        }),
    ]);

    return toMapSnapshot({ zones, cameras, alerts });
```

```ts
'use client';

import { useCallback, useEffect, useState } from 'react';

// Boolean UI preference kept in localStorage. Storage can be blocked or
// cleared, so every access is guarded and the initial value always works.
export function useStoredBoolean(key: string, initial: boolean): [boolean, (next: boolean) => void]
{
    const [value, setValue] = useState(initial);

    useEffect(() =>
    {
        try
        {
            const stored = localStorage.getItem(key);
            if (stored === 'true' || stored === 'false')
            {
                setValue(stored === 'true');
            }
        }
        catch
        {
            // Keep the initial value.
        }
    }, [key]);

    const update = useCallback((next: boolean) =>
    {
        setValue(next);
        try
        {
            localStorage.setItem(key, String(next));
        }
        catch
        {
            // Preference just won't persist.
        }
    }, [key]);

    return [value, update];
}
```

```tsx
        type: 'FeatureCollection',

            type: 'Feature',

            type: 'Feature',

            geometry: { type: 'Point', coordinates: alert.position! },

    }), [snapshot.alerts]);

    const [[west, south], [east, north]] = initialBounds(snapshot);

    return (
```

```tsx
'use client';

import { useCallback, useRef, useState } from 'react';
import type { MapRef } from 'react-map-gl/maplibre';
import type { SessionUser } from '@/lib/auth/session';
import type { AlertView, MapSnapshot } from '@/lib/types';
import { TopBar } from '@/features/shell/TopBar';
import { AlertsFeed } from '@/features/alerts/AlertsFeed';
import { CameraPanel } from '@/features/cameras/CameraPanel';
import { Legend } from './Legend';
import { MapControls, type LayerKey } from './MapControls';
import { initialBounds, MapView } from './MapView';

export function MapScreen({ snapshot, user }: { snapshot: MapSnapshot; user: SessionUser })
{
    const mapRef = useRef<MapRef>(null);
    const [selectedCameraId, setSelectedCameraId] = useState<string | null>(null);
    const [layers, setLayers] = useState<Record<LayerKey, boolean>>({ zones: true, cameras: true, alerts: true });

    const selectedCamera = snapshot.cameras.find(camera => camera.id === selectedCameraId) ?? null;

    const fitBeach = useCallback(() =>
    {
        const [[west, south], [east, north]] = initialBounds(snapshot);
        mapRef.current?.fitBounds([west, south, east, north], { padding: 80, duration: 800 });
    }, [snapshot]);

    const flyToAlert = useCallback((alert: AlertView) =>
    {
        if (alert.position)
        {
            mapRef.current?.flyTo({ center: alert.position, zoom: 18, duration: 900 });
        }
        const camera = snapshot.cameras.find(candidate => candidate.code === alert.cameraCode);
        if (camera)
        {
            setSelectedCameraId(camera.id);
        }
    }, [snapshot.cameras]);

    return (
        <main className="relative h-full overflow-hidden bg-night-950">
            <MapView ref={mapRef} snapshot={snapshot} layers={layers} selectedCameraId={selectedCameraId} onSelectCamera={setSelectedCameraId} />

            {/* Overlay grid; pointer-events pass through except on panels */}
            <div className="pointer-events-none absolute inset-0 flex flex-col gap-3 p-3">
                <TopBar user={user} camerasOnline={snapshot.camerasOnline} camerasTotal={snapshot.camerasTotal} activeAlertCount={snapshot.activeAlertCount} />

                <div className="flex min-h-0 flex-1 gap-3">
                    <div className="flex min-h-0 max-md:absolute max-md:inset-x-3 max-md:bottom-3 max-md:max-h-[45%] md:w-72">
                        <AlertsFeed alerts={snapshot.alerts} onSelect={flyToAlert} />
                    </div>

                    <div className="ml-auto flex items-start gap-3">
                        {selectedCamera && (
                            <div className="max-md:absolute max-md:inset-x-3 max-md:bottom-3 max-md:z-10">
                                <CameraPanel camera={selectedCamera} onClose={() => setSelectedCameraId(null)} />
                            </div>
                        )}
                        <MapControls
                            onZoomIn={() => mapRef.current?.zoomIn({ duration: 300 })}
                            onZoomOut={() => mapRef.current?.zoomOut({ duration: 300 })}
                            onFit={fitBeach}
                            layers={layers}
                            onToggleLayer={key => setLayers(current => ({ ...current, [key]: !current[key] }))}
                        />
                    </div>
                </div>

                <div className="pointer-events-auto absolute right-3 bottom-3 max-md:hidden">
                    <Legend />
                </div>
            </div>
        </main>
    );
}
```

```ts
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join, relative } from 'node:path';
import { describe, expect, it } from 'vitest';

const dashboardRoot = join(import.meta.dirname, '..', '..');
const skipDirectories = new Set(['node_modules', '.next', 'generated', 'migrations']);
const scannedExtensions = /\.(ts|tsx|js|mjs|cjs|py|json|ya?ml|Dockerfile)$|Dockerfile$/;

// agent.md: the dashboard must not depend on the simulator, the research API, or evaluator truth.
const forbidden: { pattern: RegExp; reason: string }[] = [
    { pattern: /from ['"](\.\.\/)+web\//, reason: 'imports the research simulator' },
    { pattern: /scripts\/server\.mjs/, reason: 'references the research API' },
    { pattern: /(localhost|127\.0\.0\.1):5174/, reason: 'calls the research API port' },
    { pattern: /artifacts\/private|examples\/[^/]+\/private/, reason: 'reads private evaluator truth' },
];

function walk(directory: string): string[]
{
    return readdirSync(directory).flatMap(name =>
    {
        const path = join(directory, name);
        if (statSync(path).isDirectory())
        {
            return skipDirectories.has(name) ? [] : walk(path);
        }
        return scannedExtensions.test(name) ? [path] : [];
    });
}

describe('dashboard boundary', () =>
{
    it('never references the simulator, research API or private truth', () =>
    {
        const self = relative(dashboardRoot, import.meta.filename);
        const violations = walk(dashboardRoot)
            .filter(path => relative(dashboardRoot, path) !== self)
            .flatMap(path =>
            {
                const text = readFileSync(path, 'utf8');
                return forbidden.filter(rule => rule.pattern.test(text)).map(rule => `${relative(dashboardRoot, path)}: ${rule.reason}`);
            });
        expect(violations).toEqual([]);
    });
});
```
